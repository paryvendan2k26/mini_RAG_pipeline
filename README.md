# Mini-RAG Pipeline

This project is a small retrieval-augmented generation pipeline for experimenting with document ingestion, chunking, retrieval, generation, and evaluation. Phase 1 implements knowledge-base loading and chunk creation from local text files.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Validate

```bash
python validate.py
```
